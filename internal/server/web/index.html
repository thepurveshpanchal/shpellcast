shpellcast {{VERSION}}

Pipe a command to a URL

Send the output of anything running in a terminal to a private web page, live, with nothing to install on the machine that produces it. Watch a long build from your phone, or hand a colleague a link instead of a screenshot.

With netcat

./long_job.sh 2>&1 | nc {{TCP_TARGET}}

The server replies with the page URL on the first line, then streams everything it receives. Works with nc, ncat, socat or busybox — anything that can open a TCP socket.

No netcat? Use bash's built-in socket

exec 3<>/dev/tcp/{{TCP_TARGET}}; head -1 <&3 & ./long_job.sh 2>&1 >&3

Over HTTP, through any proxy or TLS

./long_job.sh 2>&1 | curl -sT- {{BASE}}/i

curl prints the URL when the upload ends. To get the link up front, ask for a session first: 

read -r id url tok < <(curl -s "{{BASE}}/new?format=text" | tr '\n' ' ')
echo "$url"
./long_job.sh 2>&1 | curl -sT- -H "X-Shpellcast-Token: $tok" "{{BASE}}/i/$id"

Helper script

curl -fsSL {{BASE}}/client.sh -o ~/.local/bin/shpellcast && chmod +x ~/.local/bin/shpellcast

./long_job.sh 2>&1 | shpellcast            # prints the URL, then streams
shpellcast -- make -j8                      # or run the command for you

Watching

Open the link in a browser for a live terminal view with ANSI colour and working progress bars, or follow it from another shell: 

curl -N {{BASE}}/s/<id>/raw

What to expect

Retained output per session{{BUFFER}}
Maximum accepted per session{{QUOTA}}
Session expiry after last write{{IDLE_TTL}}

Sessions have no password: the URL is the secret, so it is random and unguessable. Anyone who has the link can read the output, and nobody who doesn't can. Links are never listed publicly and expire on their own. Don't pipe anything through here that you wouldn't put in a pastebin.
